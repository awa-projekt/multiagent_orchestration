# About awa

awa (Agentic Work Automation) is programmed by cd-bits. It is a Python library that gets business
processes running with AI agents, under limits and approvals that code enforces.

## The research project

awa is developed within the research project *Agentic Work Automation* (AWA). The project is led
by the Fraunhofer Institute for Applied Information Technology FIT, Branch Business & Information
Systems Engineering, Augsburg. Its partners are Ancud IT-Beratung GmbH, DATEV eG, Brauerei Gebr.
Maisel GmbH & Co. KG and soffico GmbH.

The research project is funded by the Bavarian Transformation and Research Foundation
(Bayerische Transformations- und Forschungsstiftung).

## Where awa stands

awa is an early, unfinished software library that is still under construction. It is not yet an
interim result of the research project.

It provides first core functions for multi-agent systems: agents, teams, workflows,
communication between agents, approvals, limits and evaluation. It is meant to become the base on
which reference architectures and decision models may later be built.

Hybrid multi-agent systems are tested on it first. In such a system, a lead agent delegates work,
and its members consult each other directly, inside limits enforced by code.

The recipes and use cases shipped with awa are small first test cases on sample data. They show
that the library applies to many kinds of processes. Along them, the library was extended with
standard functions such as connections to Microsoft 365, files including scanned PDFs and Excel
workbooks, e-mail and databases.

Proof in practice follows once the library has been hardened. Larger and more complex use cases
from companies are then applied to it.
