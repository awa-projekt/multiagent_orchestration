# Origin of the data

Test data: public or generated, not company data.

| File | Origin | License |
| --- | --- | --- |
| `sales.db` | Generated by make_data.py (fictitious), seed 20261008: 400 customers, 120 products, 6,000 orders, about 21,000 order lines, 2024-01-02 to 2026-01-09. | Generated by the project; no third-party data. |
| `targets.csv` | Generated by make_data.py (fictitious): one net revenue target per employee and year. | Generated by the project; no third-party data. |

All company, product and person names are built from invented syllables and common first
names by a fixed generator. They do not describe real companies or people; any resemblance is
coincidental. The data contains no personal data.

Run `python make_data.py` in the use case folder to write the same files again.
